# DHS_MDD_Mental_Health
Cross-sectional DHS Phase 8 study (Lesotho, Mozambique, Nepal, Zambia) assessing Minimum Dietary Diversity for Women (MDD-W) and moderate-to-severe depression (PHQ-9≥10) and anxiety (GAD-7≥10). Uses survey Poisson regression and random-effects meta-analysis, adjusting for sociodemographics and physical/sexual violence exposure.
